# 素宣墨韵 v3.0 · 矿物彩 — InkPaper 设计系统文档

> 版本：v3.0（矿物彩）｜取代 v2.0｜北极星：**纸上留痕 —— 矿物为彩，墨色为骨。**
> 基准：`.soloqueue/design/demo-v3.html`（已验收）｜策略：`.soloqueue/plan/Design/2026-08-11/inkpaper-v3-full-update.md`

## 核心理念

**纸上留痕 —— 矿物为彩，墨色为骨。** 页面如手作宣纸（纸面留痕、笔触留锋、落印留朱），**墨色五阶承担全部文字与阅读骨架；矿物五色（石青/石绿/朱砂/赭石/藤黄）承担语义与交互。**

- **v2→v3 进化**：「功能用墨，装饰用印」→ **「文字用墨，功能用石，装饰用印」** —— 阅读信息只用墨色五阶；交互语义用矿物色（石青管路径、赭石管引用警示、石绿管成功、朱砂管危险）；朱砂由 v2 纯装饰升级为「签名色」（印鉴+危险态），唯一烈色 ≤1%。
- **总量纪律**（细则见十戒第 11 戒）：色彩不过三点、石青一屏 ≤2 处、藤黄永不入文字、全页墨色面积 ≥85%。

## 一、画论依据

v3 矿物色的合法性来自「以墨为骨、以色为肉」的着色纪律；**每个矿物色决策对应一条画论出处。**

### 1.1 王希孟《千里江山图》—— 暖底承色

青绿重彩先罩赭石暖底，冷暖对比色相才立得住 → **映射**：玉白宣纸 `#FAF9F5`（R−B=+5 暖底）承载冷色矿物，绝不铺于冷白/纯白。

### 1.2 黄公望浅绛山水 —— 墨骨先行、色为薄罩

先有墨骨，再以赭石淡彩薄罩，色不掩墨 → **映射**：墨色五阶为骨架，布局/层级/正文先以墨成立；矿物色后加、少加、薄加（淡染 tint，非实色块）。

### 1.3 齐白石红花墨叶 —— 朱砂唯一烈色

墨叶托唯一朱砂，其余从简 → **映射**：朱砂为系统唯一高饱和烈色，只用于印鉴与危险态；禁霓虹、禁第二种烈色。

### 1.4 谢赫六法「随类赋彩」—— 按类赋色

按物之类别赋相应颜色 → **映射**：一色一职 —— 石青链接/导航、石绿成功、朱砂印鉴/危险、赭石引用/警示、藤黄仅图表；不得跨职。

### 1.5 新华网《不曾褪色》—— 克制纪律

> 「石青石绿的搭配只适合小范围的画龙点睛…过度则俗不可耐。」

→ **映射**：矿物色总量克制是 v3 最高纪律 —— 石青一屏 ≤2 处；五色全员到场仅限图表一处；宁少勿多。

## 二、色彩系统

### 2.1 纸 —— 玉白宣纸

- `--paper: #FAF9F5`（RGB 250,249,245），**R−B=+5** 暖底，不蓝不冷。
- 模拟**无荧光增白剂**手工宣纸（暖白而非蓝白）：**禁止纯白 `#FFF` 与蓝白冷白**（如 `#F8FAFC`、`#F5F7FA`）。
- `--paper-card: rgba(249,248,243,0.75)`：玉白同调半透纸层，用于代码块、图表、状态条。

### 2.2 骨 —— 墨色五阶（保留 v2）

| 阶 | 色值 | 角色 |
|----|------|------|
| 焦墨 | `#2B1E14` | 主文字、标题、代码关键字 |
| 浓墨 | `#5E4E3F` | 正文、摘要、标签文字 |
| 淡墨 | `#9B8B7A` | 日期、备注、导航默认、占位 |
| 清墨 | `#C5B9A5` | 边框、分隔线、水平笔触 |

墨色均带暖调（黄棕底），无冷灰蓝；层级沿焦→浓→淡，不引入第五个文字色。

### 2.3 彩 —— 矿物五色

| 色 | 色值 | 角色 | 使用位置 | 限制 |
|----|------|------|---------|------|
| 石青 | `#2B5C8A` | 链接/导航指示/选中/图表主色 | 正文链接、导航 hover/active、`::selection`、文章项竖线、系列一 | **一屏 ≤2 处**；只作小面积点色 |
| 石绿 | `#3E8E7E` | 成功态/图表次色 | 成功状态条（tint 底+3px 竖线+✓）、系列二 | 对比 3.5:1，**仅大字号/UI 图形**，禁小字号文字 |
| 朱砂 | `#B33A3A` | 印鉴+危险态（签名色） | Logo 印 22×22、页脚印 18×18、错误状态条 | **≤ 页面可视面积 1%**；烈色唯一 |
| 赭石 | `#A96A2E` | 警示/引用线/图表第三色 | 引用侧锋笔触、警示元素、系列四 | 不作文字色 |
| 藤黄 | `#D9A620` | 仅图表/装饰 | 系列五、装饰色块 | 对比 1.98:1，**禁止用于任何文字** |

### 2.4 派生色（透明化 tint）

| 变量 | 色值 | 用途 |
|------|------|------|
| `--select-bg` | `rgba(43,92,138,0.08)` | 石青 8% 淡染 · 选中背景 |
| `--azurite-line` | `rgba(43,92,138,0.30)` | 石青淡染 · 链接下划线（默认态） |
| `--malachite-tint` | `rgba(62,142,126,0.09)` | 石绿淡染 · 成功状态背景 |
| `--cinnabar-tint` | `rgba(179,58,58,0.07)` | 朱砂淡染 · 危险状态背景 |

### 2.5 色彩纪律（v3）

- **禁纯白 `#FFF`、禁蓝白、禁纯黑 `#000`**：一切色值带暖调，矿物色是唯一彩色例外。
- **文字用墨、功能用石、装饰用印**：正文与标题永不使用矿物色；交互语义一色一职（随类赋彩）；朱砂 ≤1%，全系统仅两枚印。
- **总量克制**：石青一屏 ≤2 处、藤黄禁文字、色彩不过三点、墨色 ≥85%（同十戒 11）。

## 三、交互状态映射（v3）

| 元素 | 默认 | 悬停 | 激活/当前 |
|------|------|------|-----------|
| 导航链接 | 淡墨 `--ink-light` | 石青 + 底部 1.5px 石青线（inset） | 石青线常驻 |
| 文章标题 | 焦墨，无下划线 | 浓墨 + 下划线 | — |
| 文章项 | 无指示 | 3px 石青竖线淡入（opacity 0.75、scaleY 0.35→1） | — |
| 正文链接 | 石青 + `--azurite-line` 淡染下划线 | 实石青下划线 | — |
| 引用线 | 赭石侧锋笔触（opacity 0.75），无交互 | — | — |
| 选中 `::selection` | 石青 8% 淡染 `--select-bg` | — | — |
| 成功/危险态 | 石绿/朱砂：tint 底 + 3px 同色竖线 + ✓/✕ 符号 | — | — |
| 代码关键字 | 焦墨 + 字重 500，无矿物色 | 无交互 | — |
| 按钮/切换 | 淡墨边框、浓墨文字 | 焦墨边框文字 + 石青淡染底 | — |
| 焦点 `:focus-visible` | 2px 焦墨外框 + 2px offset | — | — |

**原则**：状态由矿物色表达、文字永远用墨；石青唯一承担导航/链接；选中仅 8% 淡染。

## 四、质感与纹理

### 4.1 宣纸底纹（灰度噪点）

- 噪点**必须灰度**（`feColorMatrix type='saturate' values='0'`），禁彩色噪点；透明度固定：浅色 0.04 / 深色 0.05，不可提高。
- 浅色 `--paper-veil: none`（移除 v2 暖色底色渐变，杜绝额外暖偏）；深色为台灯暖光渐变（见第九章）。`body` 背景 = `var(--paper)` 底 + `var(--paper-veil), var(--paper-noise)` 两层图（veil fixed / noise repeat+scroll）。

### 4.2 毛笔笔触 SVG

分隔线、引用线一律 SVG 贝塞尔路径，禁止 CSS `solid`/`dashed` 硬边。

- **横笔**（清墨，全宽 6px）：`<svg class="brush-hr" viewBox="0 0 120 6" preserveAspectRatio="none" aria-hidden="true"><path d="M0,3 Q30,1 60,3 Q90,5 120,3" fill="none" stroke="var(--border-ink)" stroke-width="1.8" stroke-linecap="round" opacity="0.8"/></svg>`
- **侧锋**（v3 变更：淡墨→**赭石**，笔触不变）：`<svg viewBox="0 0 6 100" preserveAspectRatio="none" aria-hidden="true"><path d="M3,0 Q0,20 3,50 Q6,80 3,100" fill="none" stroke="var(--ochre)" stroke-width="2.2" stroke-linecap="round" opacity="0.75"/></svg>`

### 4.3 无卡片无阴影

空间划分仅靠留白、清墨细线、半透纸层；容器用 `--paper-card` + 1px `--border-ink` 边框 + 小圆角，**任何情况不用 box-shadow**。

## 五、字体与排版（保留 v2）

### 5.1 字体栈与字阶

正文/标题：`"Noto Serif SC", "Source Han Serif SC", "Songti SC", serif`；代码：`"FangSong", "LXGWenkai Mono", "Fira Code", monospace`（v3 demo 首字各增 `"TsangerJinKai02"` 金字楷 / `"JetBrains Mono"`）。

字号/行高/字重：H1 3.4rem/54px·1.3·500（Hero）；H2 1.7rem/27px·1.3·500（文章列表标题）；H3 1.4rem/22px·1.3·500（次要标题）；Body 1rem/16px·1.8·400（正文）；Small 0.9rem/14px·1.6·400（日期/备注）；Caption 0.8rem/12px·1.5·400（标签/印章辅助文字）。

### 5.2 排版纪律

字重锁 500、行高分级（标题 1.1–1.3 / 密集 1.4–1.45 / 阅读 1.5–1.55）、中文字距 0.3pt 英文 0、禁斜体 —— 细则见十戒第 5/6/7/10 戒。

## 六、设计原则（十戒 v3 版）

1. **宣纸为底**：页面背景永远使用玉白 `#FAF9F5`（或深色对应色），绝不使用纯白与蓝白。
2. **文字用墨，功能用石，装饰用印**：文字用墨色五阶；交互与语义功能用矿物色；朱砂仅用于印鉴与危险态。
3. **墨色暖调、矿物色例外**：所有墨色灰阶必须有暖调（黄棕底），矿物色是唯一的彩色例外。
4. **中文 serif**：使用衬线字体；英文 serif 标题。
5. **字重锁定**：Serif 重量锁定在 500，不使用 bold。
6. **行高分级**：紧凑标题 1.1–1.3 / 密集正文 1.4–1.45 / 阅读正文 1.5–1.55。
7. **字距调整**：中文正文 0.3pt，英文正文 0。
8. **标签背景**：必须使用实色十六进制，不使用 rgba（WeasyPrint 双重矩形 bug）。
9. **无卡片无阴影**：空间划分仅依靠留白与细线。
10. **禁止斜体**：任何地方不使用斜体。

**第 11 戒（v3 新增）· 画龙点睛**：矿物色总量克制 —— 石青一屏 ≤2 处、朱砂 ≤1%、藤黄禁文字、色彩不过三点、全页墨色面积 ≥85%；「只适合小范围的画龙点睛，过度则俗不可耐。」

> 注：十戒之名沿袭 v2；v3 修订第 2、3 条并新增第 11 戒，其余保留。

## 七、组件规范

### 7.1 导航栏
Logo（22×22 朱砂小印）+ 品牌字 + 链接 + 主题切换；背景透明，仅底部 1px 清墨线；链接状态见 §3。

### 7.2 按钮 / 链接 / 列表
交互状态见 §3 对应行（按钮/切换、正文链接、文章项、文章标题）。

### 7.3 引用块
赭石侧锋 SVG（3px，opacity 0.75）+ 浓墨文字 + 淡墨出处（`cite` 禁斜体）；竖线用 `--ochre`，不用淡墨/朱砂。

### 7.4 状态提示
成功/危险视觉见 §3；标题焦墨、详情浓墨；文字永不用矿物色；石绿 3.5:1 仅大字号/UI。

### 7.5 代码块
`--paper-card` 半透底 + 1px 清墨边框 + 左侧 3px 清墨竖线；仿宋/楷体等宽（demo JetBrains Mono 首位）；高亮**全墨**：关键字焦墨 500、字符串浓墨、注释淡墨 —— 朱砂不入高亮。

### 7.6 数据可视化
五色**唯一全员到场**之处：石青/石绿/朱砂/赭石/藤黄（系列一~五）；容器 `--paper-card` + 清墨边框；藤黄只做色块，标注/数值文字一律墨色。

### 7.7 毛笔分隔线
见 §4.2 横笔（全宽 6px，清墨，仅用于大区块分隔）。

### 7.8 印章
朱砂（`--cinnabar`）SVG 方印：Logo 22×22、页脚 18×18，`aria-hidden="true"`；全系统仅此两枚。

## 八、可访问性标准

### 8.1 实测对比度表（玉白底 `#FAF9F5` / 黛青底 `#22262E`）

| 前景 | 背景 | 对比度 | 结论 |
|------|------|--------|------|
| 焦墨 `#2B1E14` | 玉白 `#FAF9F5` | 14.4:1 | AAA · 主文字 |
| 石青 `#2B5C8A` | 玉白 `#FAF9F5` | 6.2:1 | AA · 链接 / 导航文字 |
| 朱砂 `#B33A3A` | 玉白 `#FAF9F5` | 5.2:1 | AA · 危险态 / 印章 |
| 赭石 `#A96A2E` | 玉白 `#FAF9F5` | 4.2:1 | AA · 引用线（非文字） |
| 石绿 `#3E8E7E` | 玉白 `#FAF9F5` | 3.5:1 | 仅大字号 / UI 图形，禁小字号文字 |
| 藤黄 `#D9A620` | 玉白 `#FAF9F5` | 1.98:1 | 不达标 · **禁止用于任何文字** |
| 深色模式全部矿物色 | 黛青 `#22262E` | ≥ 4.8:1 | AA · 矿物色提亮后达标 |

### 8.2 焦点指示与语义化

- `:focus-visible`：2px 焦墨外框 + 2px offset。
- 标准 HTML 标签（`nav`/`main`/`ul`/`blockquote`）+ ARIA：导航 `aria-label`、印章 `aria-hidden`、状态提示带语义文本。
- **颜色不作唯一信息载体**：链接带下划线；状态条带符号（✓/✕）与文字。

## 九、深色模式「灯下夜读」

- 底色 `#22262E` **黛青夜空** —— 冷而沉、非暖棕；与浅色玉白构成「日间暖纸/夜间冷窗」反转。
- **顶部一盏台灯**：`--paper-veil` 暖光渐变 `rgba(255,214,165,0.05)`，30% 处衰减为 0，微光即止。
- 文字**暖乳白** `#ECE4D5`（灯下纸色）；正文浓墨 `#B9AD97`；淡墨 `#7A6E5F`；边框 `rgba(255,255,255,0.08)`。
- **矿物色整体提亮一档**：

| 色 | 浅色模式 | 深色模式 |
|----|----------|----------|
| 石青 | `#2B5C8A` | `#6FA3C9` |
| 石绿 | `#3E8E7E` | `#63B5A4` |
| 朱砂 | `#B33A3A` | `#D87070` |
| 赭石 | `#A96A2E` | `#C98A4B` |
| 藤黄 | `#D9A620` | `#E0B64C` |

- 派生 tint：`--select-bg rgba(111,163,201,0.14)`、`--azurite-line rgba(111,163,201,0.42)`、`--malachite-tint rgba(99,181,164,0.12)`、`--cinnabar-tint rgba(216,112,112,0.12)`。
- 噪点 0.05 灰度；纸层 `rgba(38,43,54,0.8)`；深色矿物色对比度全部 ≥4.8:1（AA 级）。
- 覆盖：`[data-theme="dark"]` 重定义变量 + `color-scheme: dark`。
